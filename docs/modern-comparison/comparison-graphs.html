Jev against published benchmark scores

This page places Jev's own measured scores next to published scores for other models. Jev was run live, answering each question in a single direct shot with no step-by-step reasoning and no tools. Every other bar is a number we looked up from a public leaderboard or a vendor report, not a model we ran. Because the external numbers use different setups, these charts are for context, not a single controlled comparison; each chart says below its title how its conditions differ.
