# Multilingual comparison

This local review compares Jev with Qwen3.5 9B on a matched multilingual natural-language-inference task. The objective is descriptive: measure whether the two systems preserve the same decision accuracy across languages under a common, direct-answer protocol.

The evaluation uses human-translated XNLI sentences. The professional translations preserve each source premise and hypothesis; the English instruction is common across languages. We selected 1,200 distinct held-out premises per language (400 per gold label) in English, Arabic, Chinese, German, Russian, and Spanish. Each premise was tested in two option orders. Development pilots were kept separate from this test set: an English pilot established useful headroom for the selected task (Jev 84.58%, Qwen 75.42%), but no test premise or identifier was reused.

Both systems received the same task and direct-answer format. Jev used its recorded release; Qwen3.5 9B ran at temperature 0 with reasoning off and a 512-token maximum. The comparison is paired at the premise level. We computed each model's English-to-language drop and the between-model difference in those drops. Whole-premise paired bootstrap intervals use 5,000 resamples (seed 2026100316). The language-specific intervals in the [derived aggregate](../../data_report/expanded_20261003/multilingual_heldout_aggregates.json) are pointwise 95%; a sensitivity analysis uses 99% Bonferroni intervals for the five non-English comparisons. The aggregate therefore supports a compact comparison without releasing source sentences, request bodies, or per-item rows.

Most individual differences in the relative drop are uncertain; German is the clear exception in this set. Across the five non-English languages, Jev's descriptive average drop is 2.11 percentage points smaller than Qwen's, with a pointwise 95% interval of 0.43 to 3.77 points in the direction of the smaller Jev drop. This average is exploratory and should be read alongside the language-specific intervals, not as a new pooled benchmark.

The public artifact contains derived aggregates, labels, provenance, and the source paper link, not the licensed raw text. XNLI is described in [Conneau et al.](https://arxiv.org/abs/1809.05053). Icelandic and Japanese were easy controls in a separate context and are not part of this chart; no translations for them are inferred here.
